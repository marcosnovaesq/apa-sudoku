### `yarn install && yarn start`
 para rodar o projeto, deve ter npm ou yarn instalado para executar a instalaçao de dependencias

 apos rodar `yarn install && yarn start` o projeto deve abrir no navegador, caso nao abra:
 abrir uma aba em localhost:3000

 clicar no botao de pause e play 2 vezes para ele começar a rodar o algoritmo
